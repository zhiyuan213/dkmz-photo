五、一屏高度预算

估算口径：以 iPhone 14 Pro（852pt ≈ 1704rpx，扣导航与安全区约 190rpx → 可用 ≈ 1510rpx）
页面估算高度是否一屏主要占位与瘦身手段
首页≈ 1460rpx✅ 是 尺寸 10 项两列 5 行 ≈700rpx 为大头；**适用场景只在选中卡片展开**、摘要省略毫米尺寸、页脚合并成一行，共省约 280rpx
制作页≈ 970rpx✅ 是 拍摄要求折叠；尺寸卡 4 行并 3 行；主操作固定底部栏（不占内容流）
结果页≈ 1320rpx✅ 是 规格检查由「两行一条」改「一行一条」省约 160rpx；预览收窄到 360rpx；处理明细折叠
购买页≈ 1010rpx✅ 是 规则长文折叠进「购买须知」卡；两个次要按钮并排一行（原两行）
订单页≈ 760rpx + 230 × 订单数△ 1~2 单内 列表页允许随记录数滚动；单卡已压到 3 行信息 + 单行按钮
小屏机型（iPhone SE 667pt ≈ 1154rpx）：首页与结果页会略超，正常滚动即可；其余页面均在一屏内。
